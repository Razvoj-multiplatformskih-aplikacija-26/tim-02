# tim-02
TFT Insights - Aplikacija za Teamfight Tactics igricu koja omogućava pregled i filtriranje statistike šampiona i predmeta iz odigranih mečeva, istraživanje njihovih kombinacija i uspešnosti, kreiranje i čuvanje timskih postava bez interneta, kao i objavljivanje, pretragu i preuzimanje taktika drugih korisnika.
